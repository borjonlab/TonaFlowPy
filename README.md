<h1>
    About
</h1>
<p>
Processing an electrocardiogram (ECG) signal is not a trivial feat. Effective processing for ECG signals requires a multi-stage pipeline where one needs to make analytically informed decisions about filtering, removing noise, and R-peak detection corrections. Currently, most software that exists to facilitate this process is prohibitively expensive or requires technical expertise. We believe that ECG processing should be <i>free, open-source, </i> and <i> accessible </i> to researchers of all technical backgrounds.
</p>

## Building from Source

```
# Clone the repo.
git clone https://github.com/borjonlab/TonaFlowPy.git
cd TonaFlowPy

# Create a virtual environment, install dependencies.
python -m venv ./venv
source ./venv/bin/activate 
pip install -r requirements.txt

# Run and have fun!
python TonaFlow.py
```
